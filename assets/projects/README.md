# Imagenes de proyectos

Pon aqui las capturas o imagenes de tus proyectos.

Ejemplo:

- `dev/sistema-ganaderia.jpg`
- `dev/portafolio-kynova.jpg`
- `marketing/campana-marketing.jpg`

Luego edita [src/scripts/data/projects.js](../../src/scripts/data/projects.js) y cambia:

```js
image: "./assets/projects/dev/tu-imagen.jpg",
link: "https://github.com/usuario/repositorio",
```

Puedes usar `.jpg`, `.png`, `.webp` o links externos. Si la imagen local todavia
no existe, el portafolio usa una imagen temporal para que la tarjeta no se rompa.
