# Demos

`index.html` es el catálogo disponible en `/demos/`.

## Crear una invitación nueva

1. Duplica la carpeta `boda-ejemplo` dentro de `demos`.
2. Renombra la copia usando minúsculas y guiones, por ejemplo `boda-ana-luis`.
3. Edita su `index.html`, `styles.css` y `script.js`.
4. Guarda sus imágenes en la carpeta `assets` de esa misma invitación.
5. Agrega una tarjeta en `demos/index.html` con la nueva ruta.

Cada carpeta es autocontenida para evitar que los cambios de una invitación afecten a otra.
