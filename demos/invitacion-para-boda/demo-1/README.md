# Invitación de boda — Demo 1

Esta carpeta contiene un estilo completo y autosuficiente de invitación.

## Estructura

- `fase-1/`: pase y presentación inicial.
- `fase-2/`: landing completa de la boda.
- `assets/img/`: fotografías, fondos, adornos e iconos exclusivos de esta demo.
- `assets/audio/`: música exclusiva de esta demo.

## Convenciones para próximas demos

Cada diseño nuevo debe vivir en su propia carpeta hermana:

```text
invitacion-para-boda/
  demo-1/
  demo-2/
    fase-1/
    fase-2/
    assets/
      img/
      audio/
```

No compartas imágenes o audio entre demos salvo que sean recursos globales de KYNOVA.
Usa nombres de archivo en minúsculas, sin acentos y separados con guiones.
Optimiza las fotografías a WebP o AVIF antes de publicar cuando sea posible.
