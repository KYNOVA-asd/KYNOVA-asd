# Imágenes de la invitación

Sube en esta carpeta las imágenes que utilizaremos en las dos fases de la invitación.

Nombres recomendados:

- `portada.webp`
- `novios.webp`
- `ceremonia.webp`
- `recepcion.webp`
- `galeria-01.webp`
- `galeria-02.webp`

Desde una página de Fase 1 se cargan así:

```html
<img src="../../img/portada.webp" alt="Alejandro y Fátima" />
```

Desde Fase 2 se cargan así:

```html
<img src="../img/portada.webp" alt="Alejandro y Fátima" />
```

Conviene usar archivos WebP o AVIF optimizados para web. Evita espacios, acentos y mayúsculas en los nombres.
