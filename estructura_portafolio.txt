RELEVAMIENTO DEL PORTAFOLIO KYNOVA.MX
====================================
Fecha del relevamiento: 28 de septiembre de 2026
Fuente analizada: código local del repositorio KYNOVA-asd

NOTA DE ALCANCE
---------------
El sitio activo está implementado como un sitio estático en HTML, CSS y JavaScript modular.
La carpeta dist/ es la salida generada por npm run build y replica los archivos publicables.
La carpeta kynova-angular/ contiene un scaffold independiente de Angular y no forma parte del
flujo de construcción definido en el package.json de la raíz. .git/ y dependencias instaladas
se omiten del árbol porque no son código funcional del portafolio.

2. HTML Y COMPONENTES PRINCIPALES
=================================

ARQUITECTURA GENERAL
--------------------
- Documento HTML5 en español y responsive mediante viewport.
- Header compartido: logotipo circular KYNOVA, botón hamburguesa móvil y navegación a
  Nosotros, Proyectos, Costos y Contacto.
- Fuente Google Fonts: Inter, pesos 400, 500, 600, 700 y 800.
- CSS global: src/styles/main.css.
- Portada alimentada con datos JS de portfolio.js y projects.js.
- Tarjetas y modales construidos dinámicamente con createElement; el HTML contiene los
  contenedores data-* que actúan como puntos de montaje.

PORTADA: /index.html
--------------------
Título SEO: KYNOVA | Portafolio
Descripción: "Portafolio comercial de KYNOVA con proyectos de desarrollo web, marketing
digital y contacto directo."

Colores adicionales frecuentes:

TIPOGRAFÍA
----------
- Familia principal: Inter.
- Fallbacks: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif.
- Pesos cargados: 400, 500, 600, 700 y 800.
- Títulos principales fluidos con clamp; H1 del hero entre 2.8rem y 5.4rem.
- Títulos de sección entre 2rem y 3.15rem.
- Eyebrows, navegación, botones, tags y datos usan pesos fuertes (700-900), mayúsculas o
  tracking para jerarquía visual.

SISTEMA DE LAYOUT
-----------------
- Ancho máximo del contenido: 1180px.
- Contenedor: min(100% - 28px, 1180px), centrado.
- Header sticky superior, ocultable al desplazarse, fondo verde oscuro.
- Hero de dos columnas; grids principales de tres columnas.
- Catálogo de proyectos con sidebar/herramientas y grid de cards.
- CSS Grid y Flexbox como sistemas principales.
- Breakpoints principales: 1024px, 760px y 560px.
- En tablet el contenido reduce columnas; en móvil se apila a una columna y aparece el menú
  hamburguesa.

FORMAS, BORDES Y PROFUNDIDAD
----------------------------
- Radio base: 8px.
- Pills/cápsulas: border-radius 999px para navegación, tags y ciertos controles.
- Logos y avatares: círculos al 50%.
- Modales: radio 18px.
- Borde estándar: 1px solid #ded7ca.
- Sombra global fuerte: 0 24px 60px rgba(43,49,37,0.14).
- Tarjetas: sombras suaves de 12-14px de desplazamiento y 32-36px de desenfoque.

COMPONENTES VISUALES
--------------------
- Botones primary: fondo verde oliva oscuro, texto claro y sombra.
- Botones ghost: superficie clara/borde, conservando el color del texto.
- Cards: fondo marfil semitransparente, borde fino, radio de 8px y sombra suave.
- Tags: chips beige, texto oscuro, tipografía pequeña y gruesa.
- Imágenes de proyecto: aspect-ratio controlado, object-fit: cover y fallback remoto.
- Modales: overlay oscuro, panel claro de gran tamaño y bloqueo del scroll del body.
- Inputs: fondos blancos, borde beige y focus dorado translúcido.
- Interacciones: transiciones de 180-220ms para transform, sombras, fondos y color.
- Scroll suave mediante scroll-behavior: smooth.

TONO VISUAL GENERAL
-------------------
La identidad combina una base cálida y editorial (cremas, marfil y dorado) con verde oliva
oscuro para autoridad y contraste. Las tarjetas limpias, los radios contenidos y las sombras
suaves generan una presentación profesional sin verse excesivamente corporativa. Los colores
teal, rose y blue se reservan para acentos de categorías/proyectos. La interfaz prioriza
legibilidad, llamadas a la acción visibles, responsive design y navegación directa.


5. FUENTES DE DATOS Y MANTENIMIENTO
===================================

- Editar proyectos: src/scripts/data/projects.js.
- Editar servicios, skills, estadísticas y contacto: src/scripts/data/portfolio.js.
- Editar estructura de portada: index.html.
- Editar catálogo/modal: proyectos/index.html y src/scripts/projectPage.js.
- Editar estilos globales: src/styles/main.css.
- Generar dist/: npm.cmd run build.
- Ver localmente: npm.cmd run dev.
